# 陈安 · 作品集样片 v2（开场 + 第一幕 · 定位）
纯静态，无构建、无 CDN、无第三方库（3D 摄像机为手写 CSS 3D + requestAnimationFrame）。
运行：`cd site && python3 -m http.server 8000` → http://localhost:8000
- 开场：虚空中的朱红印章，长按解封（触屏轻点，键盘 Enter），印章碎裂、墨点迸散，摄像机穿过印章进入第一幕。
- 滚动驱动摄像机沿 Z 轴前进；点击任一截图/图表打开原图（可滚动长图，Esc 关闭）。
- 系统开启“减少动态效果”时，改为平面档案排版。
- assets/img 原图（逐张复制）；assets/thumb 场景用缩略图。不使用旧站视觉素材、界面或音效。
- 声音默认关闭（右上角），为 WebAudio 即时合成，无音频文件。
